
# Habbo Profile Search

### Overview
Habbo Profile Search is a web application built with PHP and Tailwind CSS that allows users to search for Habbo user profiles using the HabboAPI. The application fetches and displays detailed profile information, including user details, friends, and groups, with a responsive design optimized for both desktop and mobile devices.

#### Features
- Search Functionality: Users can enter a Habbo username to retrieve profile data.
- Profile Display: Shows user details such as username, motto, member since, last access, star gems, total experience, level, and online status.
- Friends List: Lists the user's friends with their avatars and links to view their profiles.
- Groups List: Displays the user's groups with their badges and names.
- Responsive Design: Fully optimized for mobile devices with adjusted layouts, font sizes, and spacing.
- Loading Indicator: A spinner appears during profile searches for better user experience.
- Visual Effects: Includes glow effects, hover animations, and gradient styling for a modern look.

#### Technologies Used
- PHP: Backend logic for handling API requests and rendering dynamic content.
- HabboAPI: Library for fetching Habbo user and profile data.
- Tailwind CSS: Styling framework for responsive and modern UI design.
- JavaScript: Minimal script for showing a loading spinner during form submission.
- HTML/CSS: Structure and custom styles for layout and responsiveness.
